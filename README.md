# RADIO BUTTON — ラヂオボタン
<https://hib3.github.io/radio/>

スイッチを点けると、ラジオが流れます。
勉強時や移動時に聞くために作成しました。バックグラウンド再生可能。

## 機能
- **50ch チャンネルマトリクス** — SomaFM / FIP (Radio France) / Nightride FM / Radio Paradise / LISTEN.moe など、長期運用されている HTTPS ストリームのみを収録
- **発光トグルスイッチ** — SVG で描いたスイッチが ON でフリッカー点灯 + リング回転、OFF で残光パワーダウンする
- **時計ウィジェット** — ヘッダーにデジタル時計 (コロンが明滅)
- **シグナルビジュアライザ** — CORS対応局の再生中は実際の音声スペクトラムを表示 (非対応局は状態連動の波形アニメーション)
- **SCAN** — 全チャンネルの到達性をページ内でチェックし、各スイッチの LED に OK / NG を表示
- **STOP / SHUFFLE / VOL** — 停止、ランダム選局 (NG 局は除外)、音量 (前回値を記憶)
- **キーボード操作** — ← → で選局、Space で停止 / ランダム再生
- 点灯中のスイッチをもう一度押すと消灯 (停止) します

## 構成
```

```
